# Portfolio

Faisal Elbendary's product portfolio. Plain static HTML and CSS, no framework.

- Edit page content in `src/*.html`; the shared header, footer and page titles live in `build.py`.
- Run `python3 build.py` to regenerate `index.html`, `projects.html`, `projects/*.html`, `about.html` and `contact.html`, and commit the generated files.
- Styles: `assets/styles.css`. Screenshots: `assets/<project>/`.
- Deployed on Vercel as a static site; `vercel.json` turns on clean URLs (`/projects/carna`).

Placeholders still to fill are marked in the pages with the `todo` class ("To confirm") or as hatched `ph` boxes.
